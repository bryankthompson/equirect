# docs

- `handy-sync.md`: the Handy bridge (`tools/handy-sync`): messages, timing, keys file, tests.
- `auto-mode.md`: the Handy auto mode: patterns mined from real funscripts (`tools/funscript_patterns.py`, `tools/handy_auto.py`), the presets,
  what the 1,295 scripts showed.

The Handy keys and the drive map live in `~/.config/handy/`, never in a repo. `../VIVE-FORK.md` lists what this fork changes.
